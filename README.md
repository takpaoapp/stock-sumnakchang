# 📦 ระบบบริหารคลังและขอเบิกพัสดุ สำนักช่าง (Stock Control System)

เว็บแอปพลิเคชันบริหารจัดการคลังพัสดุและงานขอเบิกจ่ายพัสดุ สำหรับ **สำนักช่าง องค์การบริหารส่วนจังหวัดตาก** ออกแบบในสไตล์เอกสารราชการที่อ่านง่าย ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และติดตั้งเป็น Progressive Web App (PWA) บนอุปกรณ์พกพา

🌐 **ทางเข้าใช้งานระบบ:** [เปิดเว็บแอปพลิเคชัน](https://takpaoapp.github.io/stock-sumnakchang/) *(สำหรับเจ้าหน้าที่ผู้ได้รับสิทธิ์เข้าใช้งานเท่านั้น)*

---

## ✨ ความสามารถหลักของระบบ

- **📊 ทะเบียนคุมสต็อกและบัตรควบคุมพัสดุ:** ติดตามรายการวัสดุแยกตามหมวดหมู่ แจ้งเตือนเมื่อพัสดุคงเหลือต่ำกว่าเกณฑ์ขั้นต่ำ พร้อมระบบค้นหาแบบเรียลไทม์
- **📝 ระบบขอเบิกและพิมพ์ใบเบิกพัสดุ (A4):** สร้างเอกสารขอเบิกพัสดุ แก้ไข และสั่งพิมพ์แบบฟอร์มราชการขนาด A4 ทั้งแบบรายฉบับและพิมพ์แยกชุดตามผู้ขอเบิก
- **📷 สแกนใบเสร็จด้วย AI รับเข้าคลัง:** รองรับการถอดรายการรับเข้าพัสดุจากภาพถ่ายใบส่งของ/ใบเสร็จรับเงินเพื่อช่วยบันทึกยอดเข้าคลังอย่างรวดเร็ว
- **📒 ทะเบียนบัญชีวัสดุ (พ.ด. ๔):** ตรวจสอบประวัติความเคลื่อนไหว รับ-จ่าย-คงเหลือ ย้อนหลัง พร้อมสั่งพิมพ์ตามแบบฟอร์มบัญชีวัสดุขนาด A4 แนวนอน
- **📅 รองรับการปิดงวดปีงบประมาณ:** แยกจัดเก็บประวัติรายการย้อนหลังตามปีงบประมาณและยกยอดคงเหลือสู่ปีถัดไปได้อย่างเป็นระบบ
- **🔐 ระบบยืนยันตัวตนและกำหนดสิทธิ์ (Security & RBAC):** ตรวจสอบสิทธิ์ผู้ใช้งานและการถือครองเซสชันจากฝั่งเซิร์ฟเวอร์ แยกบทบาทเจ้าหน้าที่คลังและผู้ดูแลระบบ พร้อมระบบพักหน้าจอล็อคอัตโนมัติ

## 📁 ไฟล์สำหรับ GitHub Pages Wrapper

เพื่อความปลอดภัยของข้อมูลและระบบภายในองค์กร Repository สาธารณะนี้จัดเก็บเฉพาะไฟล์หน้าห่อหุ้มสำหรับ GitHub Pages และ Web App Manifest เท่านั้น:

```text
├── index.html       # Frontend Shell & Viewport Wrapper สำหรับ GitHub Pages / PWA
├── manifest.json    # PWA Web App Manifest
├── favicon.ico      # ไอคอนหลักของเว็บแอปพลิเคชัน
├── icon-192.png     # ไอคอน PWA ขนาด 192x192
├── icon-512.png     # ไอคอน PWA ขนาด 512x512
├── README.md        # ภาพรวมระบบสำหรับ Repository สาธารณะ
└── CHANGELOG.md     # สรุปบันทึกการอัปเดตเวอร์ชัน
```
